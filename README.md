# Meowly

Meowly is a kitten-themed social app for sharing posts and keeping up with friends.

## Features

- Create an account and log in
- Share posts with everyone or friends
- Browse the feed and follow other users
- View your friends
- Responsive kitten-inspired interface

## Tech stack

- React and JavaScript
- Vite
- React Router
- Bootstrap 5 and custom CSS
- REST API for authentication, posts, and follows

## Run locally

```bash
npm install
npm run dev
```
